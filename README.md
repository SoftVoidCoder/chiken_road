# chiken_road — Crossy Chicken

Аркада в стиле **Crossy Road** для **Яндекс Игр**: курица перебегает бесконечную дорогу, вид строго сверху.

Вся графика — **2D-модели, нарисованные кодом** на Canvas 2D (ни одного png/svg-файла):
курица (шаг, прыжок, squash & stretch, взмах крыльями), 6 типов машин, брёвна и лилии,
поезд с вагонами, деревья, камни, монеты, орёл. Звук синтезируется на WebAudio — тоже без файлов.
Весь проект — 24 КБ архива, внешних зависимостей нет.

```
├── index.html    — разметка, HUD, оверлеи (меню/пауза/конец игры), стили
├── platform.js   — интеграция с Yandex Games SDK v2 + фолбэк для локального запуска
├── game.js       — движок: мир, физика клеток, 2D-спрайты, звук, ввод
└── dev/smoke.mjs — автотест движка в Node (заглушки DOM/Canvas)
```

## Играть

* **Онлайн с этого репозитория:** включите GitHub Pages → Settings → Pages → Source:
  `Deploy from a branch` → `main` / `/ (root)`. Игра откроется по адресу
  `https://softvoidcoder.github.io/chiken_road/` — `index.html` лежит в корне, сборка не нужна.
* **Локально без сервера:** откройте `index.html` двойным кликом.
* **С сервером** (нужен для честной проверки поведения SDK):

```powershell
python -m http.server 8080 --bind 127.0.0.1
# затем http://127.0.0.1:8080/
```

Без площадки SDK не найдётся — `platform.js` это переживёт и включит фолбэк (сохранения в `localStorage`).
Параметры адресной строки:

* `?ysdk=off` — принудительно локальный режим;
* `?debug=1` — показать кнопку «Продолжить за рекламу» без реального SDK (проверка возрождения).

## Управление

| Платформа | Действие |
|---|---|
| Клавиатура | `WASD` / стрелки — шаг (удержание = идти), `Space` — вперёд, `P` / `Esc` — пауза, `M` — звук |
| Телефон | тап — шаг вперёд, свайп — в сторону |

Правила: машины и поезд убивают, в воде можно ехать только на бревне или лилии,
течением может унести за край поля, а если стоять на месте дольше ~7 секунд — прилетит орёл.
Счёт = максимальный достигнутый ряд, монеты собираются и копятся между забегами.

## Загрузка в консоль Яндекс Игр

1. Соберите архив с `index.html` **в корне** (README и `dev/` в архив не нужны):

   ```powershell
   Compress-Archive -Path index.html,platform.js,game.js -DestinationPath chiken_road.zip -Force
   ```

2. Консоль разработчика → **Создать черновик** → тип «Игра» → загрузите архив.
3. Включите **показ рекламы** — код уже вызывает `showFullscreenAdv`
   (не чаще 1 раза в минуту и не раньше 12 секунд забега) и `showRewardedVideo` для продолжения.
4. Рейтинг: создайте таблицу лидеров (например, `best`) и впишите её имя в `platform.js`:
   ```js
   var LEADERBOARD_NAME = 'best';   // '' = рейтинг выключен
   ```
   Очки отправляются автоматически в конце каждого забега.
5. Липкий баннер (по желанию): `USE_STICKY_BANNER = true` в `platform.js`.
6. Отправьте черновик на модерацию.

### Что из требований площадки уже реализовано

* `YaGames.init()` + `features.LoadingAPI.ready()` — сообщаем о готовности игры.
* `features.GameplayAPI.start()/stop()` — вызываются на старте, паузе, конце забега и во время рекламы.
* Межстраничная реклама — с кулдауном 62 с и только после забега длиннее 12 с.
* Rewarded video — возрождение (один раз за забег), с корректной обработкой `onError`.
* Пауза и выключение звука во время рекламы, авто-пауза при потере фокуса вкладки.
* Прогресс: `player.setData/getData` + зеркало в `localStorage` (если игрок не авторизован).
* Локализация ru/en по `environment.i18n.lang`.
* Никаких внешних ресурсов: только сам SDK. Адаптивный canvas, `touch-action: none`, свайпы, DPR до 2.

## Как расширять

| Что добавить | Где |
|---|---|
| Новый язык | объект в `STRINGS` в `platform.js` (ключи те же, что в `ru`) |
| Новый тип машины | `KIND` (длина/скорость) + ветка в `drawVehicle` + вес в `genRoad` |
| Новый тип препятствия | `genGrass` (запись в `obstacles`) + функция рисования + вызов в `render` |
| Другая сложность | `difficulty()` и коэффициенты в `makeLane` (скорость, зазоры) |
| Украшения ряда | `drawGrass` / хеш-функция `hash01` для детерминированного декора |

## Автотест

`dev/smoke.mjs` прогоняет движок в Node с заглушками DOM/Canvas: загрузка, старт, движение,
смерть, возрождение, вода, поезд, монеты, ресайз, пауза, 4000 кадров случайного ввода.

```powershell
node dev/smoke.mjs
```
