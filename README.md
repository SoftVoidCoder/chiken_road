# chiken_road — Crossy Chicken

Аркада в стиле **Crossy Road** для **Яндекс Игр**: курица перебегает бесконечную дорогу, вид строго сверху.

Вся графика — **2D-модели, нарисованные кодом** на Canvas 2D (ни одного png/svg-файла):
курица (шаг, прыжок, squash & stretch, взмах крыльями), **11 типов машин**, брёвна и лилии,
поезд с вагонами, деревья, камни, монеты, орёл. Звук синтезируется на WebAudio — тоже без файлов.
Есть **три уровня сложности** и **8 скинов курицы**, которые покупаются за монеты.
Весь проект — около 30 КБ архива, внешних зависимостей нет.

```
├── index.html    — разметка, HUD, оверлеи (меню/пауза/магазин/конец игры), стили
├── platform.js   — интеграция с Yandex Games SDK v2 + фолбэк для локального запуска
├── game.js       — движок: мир, физика клеток, 2D-спрайты, звук, ввод
└── dev/smoke.mjs — автотест движка в Node (заглушки DOM/Canvas)
```

## Играть

* **Онлайн с этого репозитория:** включите GitHub Pages → Settings → Pages → Source:
  `Deploy from a branch` → `main` / `/ (root)`. Игра откроется по адресу
  `https://softvoidcoder.github.io/chiken_road/` — `index.html` лежит в корне, сборка не нужна.
* **Локально без сервера:** откройте `index.html` двойным кликом.
* **С сервером** (нужен для честной проверки поведения SDK):

```powershell
python -m http.server 8080 --bind 127.0.0.1
# затем http://127.0.0.1:8080/
```

Без площадки SDK не найдётся — `platform.js` это переживёт и включит фолбэк (сохранения в `localStorage`).
Параметры адресной строки:

* `?ysdk=off` — принудительно локальный режим;
* `?debug=1` — показать кнопку «Продолжить за рекламу» без реального SDK (проверка возрождения).

## Управление

| Платформа | Действие |
|---|---|
| Клавиатура | `WASD` / стрелки — шаг (удержание = идти), `Space` — вперёд, `P` / `Esc` — пауза, `M` — звук |
| Телефон | тап — шаг вперёд, свайп — в сторону |

Правила: машины и поезд убивают, в воде можно ехать только на бревне или лилии,
течением может унести за край поля, а если стоять на месте дольше 5–11 секунд — прилетит орёл.
Счёт = максимальный достигнутый ряд, монеты собираются и копятся между забегами.

### Трафик

До этой правки дороги генерировались **пустыми**, и машин в игре не было вообще: в `makeLane`
длина бралась как `kind.len`, где `kind` — строка (`'car'`), поэтому `count` становился `NaN`
и лента не заполнялась ни одним объектом. Теперь длина берётся из `KIND[kind].len`, а на случай
`NaN` добавлена страховка — молча пустой дороги больше не будет. Сейчас в ряду 5–9 машин,
просвет между ними 1.9–2.3 клетки, машина проезжает точку раз в 1.0–1.8 секунды
(зависит от сложности).

## Сложность

Режим выбирается в главном меню (три кнопки над «Играть») и запоминается между запусками.
У каждой сложности **свой рекорд** — в HUD и в меню показывается рекорд текущего режима.

| Режим | Поток машин | Зазоры | Разгон | Реки | Орёл | Монеты на траве | За 10 рядов |
|---|---|---|---|---|---|---|---|
| 🌿 Легко | −20 % скорости | +34 % | мягкий (×0.70) | медленнее (×0.86) | ждёт 11.5 с | ×0.85 | +2 |
| 🐔 Обычно | базовый | базовые | обычный | базовый | 7.5 с | ×1.00 | +2 |
| 🔥 Сложно | +22 % скорости | −22 % | крутой (×1.32) | быстрее (×1.16) | 5.4 с | ×1.40 | +3 |

Плотность потока подобрана так, чтобы режимы реально различались. Бот-игрок
(наивная стратегия «прыгай, когда рядом нет машины») в среднем проходит
**26 рядов на «легко», 13 на «обычно» и 7 на «сложно»**, лучший забег — 117 / 65 / 24.

## Монеты

Монеты копятся между забегами и тратятся на скины. Два источника:

* **подбор** — монеты лежат на травяных рядах (кластерами до трёх штук), шанс зависит от сложности;
* **дистанция** — каждые 10 рядов начисляется бонус: +2 на «легко» и «обычно», +3 на «сложно».

Средний забег бота приносит **4.7 монеты на «легко», 1.9 на «обычно» и 1.1 на «сложно»** —
короткий забег на «сложно» выгоднее по множителю, но короче по дистанции, поэтому суммарно
монет в нём меньше. Первый скин (30 монет) окупается примерно за 6–16 забегов.

## Скины

Магазин открывается из главного меню и из паузы. Скины покупаются за монеты,
которые копятся между забегами, и сразу надеваются — превью в магазине рисуется
той же самой моделью курицы на отдельном маленьком canvas.

| Скин | Цена | Чем отличается |
|---|---|---|
| Классика | 0 | белая курица из оригинала |
| Цыплёнок | 30 | маленький, жёлтый, в пуху |
| Разбойник | 70 | бандана и повязка на глаз |
| Ниндзя | 120 | тёмный, с развевающейся лентой |
| Зомби | 170 | зелёный, со швами и красными глазами |
| Робот | 230 | металл, визор, антенна с мигалкой и заклёпки |
| Золотая | 300 | золото с бегущим бликом и искрами |
| Радуга | 400 | палитра переливается по кругу, светящийся контур |

## Загрузка в консоль Яндекс Игр

1. Соберите архив с `index.html` **в корне** (README и `dev/` в архив не нужны):

   ```powershell
   Compress-Archive -Path index.html,platform.js,game.js -DestinationPath chiken_road.zip -Force
   ```

2. Консоль разработчика → **Создать черновик** → тип «Игра» → загрузите архив.
3. Включите **показ рекламы** — код уже вызывает `showFullscreenAdv`
   (не чаще 1 раза в минуту и не раньше 12 секунд забега) и `showRewardedVideo` для продолжения.
4. Рейтинг: создайте таблицу лидеров (например, `best`) и впишите её имя в `platform.js`:
   ```js
   var LEADERBOARD_NAME = 'best';   // '' = рейтинг выключен
   ```
   Очки отправляются автоматически в конце каждого забега.
5. Липкий баннер (по желанию): `USE_STICKY_BANNER = true` в `platform.js`.
6. Отправьте черновик на модерацию.

### Что из требований площадки уже реализовано

* `YaGames.init()` + `features.LoadingAPI.ready()` — сообщаем о готовности игры.
* `features.GameplayAPI.start()/stop()` — вызываются на старте, паузе, конце забега и во время рекламы.
* Межстраничная реклама — с кулдауном 62 с и только после забега длиннее 12 с.
* Rewarded video — возрождение (один раз за забег), с корректной обработкой `onError`.
* Пауза и выключение звука во время рекламы, авто-пауза при потере фокуса вкладки.
* Прогресс: `player.setData/getData` + зеркало в `localStorage` (если игрок не авторизован).
  Хранятся: общий рекорд `cc_best`, рекорды режимов `cc_best_easy/normal/hard`, монеты `cc_coins`,
  сложность `cc_diff`, купленные скины `cc_skins` и надетый скин `cc_skin`.
* Локализация ru/en по `environment.i18n.lang` (сложности, скины и магазин тоже переведены).
* Никаких внешних ресурсов: только сам SDK. Адаптивный canvas, `touch-action: none`, свайпы, DPR до 2.

## Как расширять

| Что добавить | Где |
|---|---|
| Новый язык | объект в `STRINGS` в `platform.js` (ключи те же, что в `ru`) |
| Новый тип машины | `KIND` (длина/скорость) + цвета в `CAR_COLORS` + ветка в `drawVehicle` + вес в `genRoad` |
| Новый тип препятствия | `genGrass` (запись в `obstacles`) + функция рисования + вызов в `render` |
| Другая сложность | новая запись в `DIFFS` (+ строки `diff*` в `platform.js`, кнопка в `#segDiff`) |
| Новый скин | запись в `SKINS` (палитра + цена) и, если нужны украшения, ветка в `drawSkinExtra` |
| Украшения ряда | `drawGrass` / хеш-функция `hash01` для детерминированного декора |

## Автотест

`dev/smoke.mjs` прогоняет движок в Node с заглушками DOM/Canvas: загрузка, старт, движение,
смерть, возрождение, вода, поезд, монеты, ресайз, пауза, три сложности, рекорды по режимам,
все типы машин в потоке, покупка и надевание скинов, отрисовка каждого скина, меню паузы,
магазин скинов, 4000 кадров случайного ввода.

```powershell
node dev/smoke.mjs
```
